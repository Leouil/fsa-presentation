# Homework 1: XBRL Fundamentals

## Overview
This presentation teaches you how SEC filings use XBRL (eXtensible Business Reporting Language) to standardize financial data. By the end, you'll know how to navigate a 10-K, identify XBRL tags, and extract balance sheet numbers.

## What You'll Learn
1. What XBRL is and why the SEC requires it
2. How to read the US GAAP Taxonomy
3. Hands-on: navigating SEC EDGAR for a real 10-K
4. Extracting balance sheet numbers via XBRL tags
5. Verifying that Assets = Liabilities + Equity

## Key XBRL Tags (Tesla 2022 10-K)
| Tag | Description |
|-----|-------------|
| `us-gaap:AssetsCurrent` | Total Current Assets |
| `us-gaap:Assets` | Total Assets |
| `us-gaap:LiabilitiesCurrent` | Total Current Liabilities |
| `us-gaap:Liabilities` | Total Liabilities |
| `us-gaap:StockholdersEquity` | Total Shareholders' Equity |
